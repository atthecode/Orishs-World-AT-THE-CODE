# Orish's World @ THE CODE — free-first V1 build plan

## Completed foundation through V1.14
1. Mobile-first PWA shell and premium AT THE CODE visual direction.
2. Birth–16 age experience model, including parent-led 0–2 mode.
3. Local free Orish speech and safe scripted prompt prototype.
4. Reusable local game architecture.
5. Security, child safety, privacy, AI safety and threat-model foundations.
6. Parent Studio local adult PIN gate with Web Crypto PBKDF2 verification.
7. Minimal child profiles and family active-profile switching.
8. Curriculum Engine starter mappings by age band and framework.
9. Private parent-goal → child-facing mission blueprint without exposing the parent's wording.
10. Automatic local Learning Passport evidence for completed learning activities.
11. Local export/print of an active child's prototype learning record, excluding private parent-request text.
12. Saved Parent Studio missions appear as playable Mission HQ activities.
13. Morning and bedtime routine editor + child-facing sequence with no behaviour score.
14. Kitchen Lab parent inventory and equipment setup.
15. Kitchen recipe matcher only marks genuinely matched starter recipes ready.
16. Kitchen steps use Child / Together / Grown-Up roles with adult-only heat/knife handling.
17. Age Game Engine supplies distinct content for all six age bands across five game families.
18. 0–2 game mode records shared participation rather than independent score.
19. 13–16 game mode uses mature language, evidence evaluation, systems thinking and unfamiliar problems.
20. Science World exposes multiple investigations.
21. Explorer Rewards Engine stores profile-specific stars, activity counts, badges and cosmetic milestones.
22. Repeat-reward limiting avoids endless reward grinding.
23. No reward shop, real-money currency, paid loot, behaviour grading or food-based rewards.
24. **Make With Orish** now contains 30 age-adapted offline maker variants across Paper Flight, Bridge, Parachute, Origami Geometry and Mini-Book projects.
25. Maker projects include age-specific safety notes, materials, investigation questions, build steps and curriculum-style objectives.
26. Maker completion records learning/evidence only — no child photo upload is required.
27. **Creative Studio** contains 24 age-adapted design briefs across world-building, visual narrative, habitat/system design and symbol/interface design.
28. Creative Studio deliberately does not store the child's artwork, handwriting or story text.
29. **Visual Sort Engine** adds a reusable richer interaction model with tap-zone and drag/drop interaction.
30. Visual sorting changes substantially by age, from shared early sorting through teen scientific reasoning classification.
31. Visual activity evidence records classification learning without preserving unnecessary child-generated conversation or media.

32. **Kitchen Lab V1.6** expands to 24 recipes across Bread / Butter / Cakes / Microwave Cakes / No-Heat / Family Baking with measurement switching, scaling and Cook Mode.
33. **Family Clubhouse V1.7** adds 36 age-adapted cooperative family activities across quiz, safe treasure hunt, science, cooking, story and build challenges.
34. Family Clubhouse requests no family names and stores no public profiles, recordings, individual family scores, stranger contacts or location-sharing data.
35. Family completion records shared learning only and uses the existing private Learning Passport/Rewards systems.
36. **Accessibility Centre V1.8** adds local per-profile text size, contrast, reduced-motion, spacious-text, simplified-visual and spoken-support controls.
37. Accessibility changes presentation rather than lowering curriculum objectives, and no diagnosis is requested.
38. **Memory/Matching Engine V1.8** adds a second richer native-button visual game engine across all six age bands.
39. Memory games use no timer/ranking and range from shared picture matching through teen scientific-reasoning concept matching.
40. Memory completion can feed the existing private Learning Passport and Rewards systems.
41. **Good News Beacon V1.9** adds six manually approved demo cards with age-adaptive positive-news/media-literacy prompts and no live feed.
42. Good News reading is not scored, rewarded or stored as behavioural history.
43. **Parent Learning Summary V1.9** creates 7-day / 30-day / all-record views from Learning Passport + reward totals only.
44. Parent summaries explicitly exclude Parent Studio wording, Orish chat text, family discussion content, artwork, photos, voice and location.
45. **Observation Lab V1.10** adds a third reusable visual game engine across all six age bands.
46. Observation play progresses from shared Look & Find to hidden-object scanning, Spot What Changed, evidence comparison and teen observation-vs-inference reasoning.
47. Observation Lab requires no child camera/photo upload and uses native tap/click/keyboard controls with no countdown or leaderboard.
48. Observation completion stores only compact learning/evidence data when enabled; it does not store screenshots, child images or scene recordings.

49. **Logic Lab V1.11** adds age-adaptive sequencing from parent-led first/next/last through teen investigation dependency planning.
50. Logic Lab has no countdown or leaderboard and includes accessible move-earlier / move-later controls.
51. Logic completion can feed compact Learning Passport evidence and Explorer Rewards.
52. **Reading & Keyboard Lab V1.12** adds a reusable literacy/keyboard engine across all six age bands.
53. Literacy scales from parent-led first words through initial sounds, word building, spelling, comprehension and teen precision editing.
54. Keyboard practice has no speed score or public ranking; accuracy, revision and accessibility are prioritised.
55. Typed practice answers remain transient UI state and are not copied into Learning Passport exports.
