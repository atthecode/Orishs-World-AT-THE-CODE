# Orish's World @ THE CODE

**Current prototype: V1.19 — Release Readiness** — V1 feature-complete free-build prototype

A mobile-first installable PWA foundation for Orish's World, built directly in code with a **£0 development stack**. No Emergent, paid builder, paid AI API, advertising SDK or analytics tracker is required for this prototype.

## Release status

V1.19 completes the core V1 feature build and focuses on safer prototype release preparation. The connected world, age-adaptive learning engines, Parent Studio, safety controls, Learning Passport, Orish Intelligence layer, Kitchen Lab, Family Clubhouse, Science/Mystery investigations, financial/legal literacy and offline PWA shell are all included in this repository.

This remains a prototype. Physical-device QA, production authentication/backend work, formal privacy/safeguarding review and App Store/TestFlight preparation are separate release steps.

## Important prototype boundary

Browser local storage and a local PIN are not a production child-data security system. Do not enter real sensitive child information, medical details or safeguarding information. Before live family, school or service use, add real adult authentication/authorization, secure backend data boundaries, formal privacy/safeguarding design, testing and legal review appropriate to the deployment.

## Cost rule

The core code project stays free-first. Any future feature that genuinely needs a paid external service must be separated, clearly flagged and explicitly approved before being connected.
