# Orish's World Storefront V1

Zero-builder storefront designed for free static hosting on Cloudflare Pages.

## Included
- Responsive mobile-first Orish's World home/shop
- Featured Too-Fast Rocket Living Storybook
- Books, Digital Storybooks, Activity Packs and Artwear
- Rocket T-shirt in French Navy + Gold direction
- Product filters and quick-view modals
- Local preview shopping bag
- Parent Corner/newsletter UI

## Product artwork
The storefront expects the owner's exact book spread at:

`storefront/assets/too-fast-rocket-book.jpg`

The downloadable website package created in ChatGPT already includes this exact supplied image. Upload the same image to that path before publishing this GitHub branch.

## Deliberately NOT connected yet
Stripe payments, print-on-demand fulfilment, authentication, digital delivery, live newsletter delivery and shipping rates. Keep these off until products/prices/policies are approved.

## Cloudflare Pages
This is a static site. Point Cloudflare Pages at the `storefront` folder; no framework build is required.
