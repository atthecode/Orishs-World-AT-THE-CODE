# Orish’s World V1.21 — Cinematic Interactive Partner Showcase

## What this mode is

This is not a static slide deck. The showcase is a guided, animated doorway into the working prototype. It uses live scene transitions, moving visual layers, Orish speech, tappable hotspots and direct launches into real prototype activities.

## 3-minute live walkthrough

1. Open **Show Prototype Demo** from the home screen. The opening scene moves and presents Orish as the guide.
2. Tap **Guided tour** to let the five visual chapters progress automatically, or tap the chapter rail manually.
3. In **Why Orish**, tap a glowing hotspot or **Try the age-6 world**. This opens the actual 4–6 child experience without changing a saved profile.
4. Return to the showcase and open **Learning world**. Tap **Fossil Detective**, **Science World** or **Evidence Detective** to enter working learning engines.
5. Open **Playable skills** and launch Maths, Reading or Memory directly from the scene.
6. Open **Safety layer** to show that parent controls, restricted routes and local-first boundaries exist before live generative AI is connected.
7. Open **Cloud-ready**. The animated network shows where a secure AI gateway, moderation, controlled generation and elastic compute could be added later.
8. Finish by explaining the cost model: trial usage → measured cost per activity → measured cost per child → useful free allowance → sustainable subscription.

## Important prototype status

This is a development prototype, not a production child-data service. Live generative AI, unrestricted open-web search, public child social features, location, and child camera/uploads remain disabled. Production deployment still requires production authentication/backend work, physical device and accessibility testing, formal safeguarding/privacy/security review, and appropriate legal review.

Explain that this child-facing layer is AT THE CODE branded and deliberately does not expose an external 3D service, photo upload or camera. ## V1.27 — Open Voice Foundation
The partner prototype can now demonstrate the privacy architecture for a future natural talking Orish: explicit parent opt-in, child tap-to-talk, short bounded microphone turns, interruption of current speech, a private self-hosted gateway and an approved learning-router boundary. The demo remains useful without paid AI: if a local STT/TTS stack is not installed, typed Orish and device read-aloud still work. This is an engineering/safety foundation, not a claim that production child voice infrastructure is complete.
