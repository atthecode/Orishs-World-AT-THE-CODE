# Premium Orish Visual Asset Map

This file controls the Phase A image pass. No major image should be added without a defined subject, use and visual purpose.

## Character continuity

Every Orish image must depict the same young Black boy with locs, the same facial identity/proportions and the same core navy/cyan/black visual language with restrained gold AT THE CODE details. Clothing may change by world but the character must remain unmistakably Orish.

## Visual quality rules

- Premium animated-film-quality stylised 3D.
- Avoid flat clipart and generic stock imagery.
- Avoid unrelated/random children as the lead image.
- Use inclusive supporting characters when a scene genuinely benefits from them, including girls naturally as scientists, explorers, builders and leaders.
- Avoid an all-blue palette: use the wider Orish World palette of navy/cyan plus turquoise, gold, lavender, violet, coral, peach, mint, warm cream, natural green and cosmic purple.
- Images must remain readable on mobile crops.
- Compress final assets to WebP/AVIF where appropriate and keep large decorative images lazy-loaded when possible.

## Acceptance rule

Before committing an image, verify: IMAGE ↔ ACTIVITY NAME ↔ SUBJECT ↔ GAMEPLAY. If any one of those is mismatched, do not ship it.
